# UsWeatherNow 
A simple .NET 10.0 WinForms app that displays a map of the current weather in the United States.

## Features
* Great project for getting started with maps or weather services.
* No dependencies on GitHub packages or third-party components.
* Shows cloud cover and rain.
* Uses free web service APIs from NOAA (National Oceanic and Atmospheric Administration).
* No API keys required.
